#Atividade 5 - Loja de Games Retro 🎮

Este repositório contém a resolução da atividade da **Aula 5 (HTML parte 1)**, ministrada pelo professor Andre Luis Denani. O objetivo do desafio foi criar uma página promocional compacta e funcional para a loja fictícia **GameZone Retro**, utilizando HTML puro e respeitando restrições rígidas de tamanho.

## 🎯 Objetivo do Projeto

Desenvolver uma página web promocional estruturada em HTML básico com, no máximo, **50 linhas de código**, garantindo a presença de elementos essenciais de navegação, tabelas, imagens e listas.

## 📋 Requisitos Implementados

O projeto cumpre 100% dos critérios de avaliação estabelecidos:

- [x] **Estrutura Básica:** Uso correto de tags estruturais, títulos, parágrafos, **negrito** e *itálico*.
- [x] **Lista:** Inclusão de uma lista de consoles clássicos/jogos de destaque.
- [x] **Navegação:** Implementação de um link externo e uma âncora interna para navegação fluida.
- [x] **Mídia:** Inclusão de uma imagem temática sobre a cultura de jogos retrô.
- [x] **Tabela:** Criação de uma tabela de produtos e preços contendo o mínimo de 3 itens.
- [x] **Código Limpo:** Respeito estrito ao limite máximo de **50 linhas** de código HTML puro.

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Sem estilização CSS, com foco total na estrutura e semântica).
